## 🚗 Cloud-Based Pothole Detection System

**Application No. 202541021974** · **Patent pending**

| | |
|---|---|
| Applicant | VIT-AP University |
| Filed | 11 March 2025 |
| Official title | System and Method for Detecting Potholes and Providing Adaptive Notifications to Users in Real-Time |
| Inventors | Srinivas Arukonda, Pakala Dishitha, Aravapalli Ramya, Shaik Mubashira Asma |

**Problem:** Drivers get little advance warning of road hazards, which leads to accidents and vehicle damage.

**Solution:** A cloud-based AI system for real-time pothole detection using YOLOv4 computer vision, ESP32 camera modules and IoT sensors. GPS coordinates are transmitted to Google Firebase Cloud, and drivers receive adaptive notifications through a mobile app. The system also integrates an STM32 microcontroller and ultrasonic sensors for vehicle-aware adaptive headlight control.

**My role:** Co-inventor. Conceived the idea and developed the system as part of a four-member inventor team.

**Verify:** Search Application No. `202541021974` on the [Indian Patent Office search portal](https://iprsearch.ipindia.gov.in/PatentSearch/PatentSearch/ViewApplicationStatus).

`YOLOv4` `ESP32` `IoT` `STM32` `Google Firebase` `Computer Vision`
